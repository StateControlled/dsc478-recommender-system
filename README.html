1. About

The objective of this project was to create a recommender system. This system takes collected user rating for books from the website Goodreads.com and uses this to predict the rating for a book from a user who has not rated that book.

2. Run

2.1 Setup

Install all required libraries: 

                python -m pip install -r requirements.txt

Requires Python 3.12 or later.
No bundled virtual environment.

2.2 Data Analysis

DataDownload.py is dedicated solely to downloading the data required to run the recommender system.

The file data-download/targets.txt contains a list of genres that will be targeted for analysis and for which relevant data will be downloaded. Valid genres are 'children', 'comics_graphic', 'fantasy_paranormal', 'history_biography', 'mystery_thriller_crime', 'poetry', 'romance', and 'young_adult'.

By default, targets.txt will only point the system to look at the 'fantasy_paranormal' genre. This is to focus the system and (hopefully) influence more accurate predictions. Additional genres, listed above, may be added manually to expand the system's knowledge.

2.2.1 Download the data

Download the data for each targeted genre from the source and save to local disk. This step only needs to be executed once. 

                python -m data-download.DataDownload --out data/archive/ --genres data-download/targets.txt

2.2.2 Start analysis and initialize recommender system

                python -m recommender.Analyze --input data/archive/ --genres data-download/targets.txt

Running this command as depicted will result in a pared-down dataset with 680 unique users and 500 unique books. Users will have read a minimum of 20 books with an average of 29.35 books per user. One of the major outputs is a user x book rating matrix.
Several files will be saved to disk that the recommender system will load later.

Additional options
--max-lines : default=500000
Maximum number of lines to read from a file. This will not be the final number of unique users or books.
--max-books : default=500
Maximum number of unique books to consider. If the dataset is small, there may be fewer books represented.
--min-read : default=20
Filter for users that have read the minimum number of books. Users who have read fewer books will be dropped.

2.3 The Recommender System

2.3.1 Recommending a book to a user

Predict a user's rating for a given book.

                python -m recommender.Recommender --predict-for --user 12 --book 40

Recommend top-n number of books to a user.

                python -m recommender.Recommender --recommend --user 12 --top-n 5

2.3.2 Evaluation

Evaluate the accuracy of the model.

                python -m recommender.Recommender --evaluate --test-ratio 0.2 --k 10

Compare plain vs cluster-aware CF.

                python -m recommender.Recommender --evaluate --clusters 4

Print cluster info.

                python -m recommender.Recommender --cluster-info --clusters 4
